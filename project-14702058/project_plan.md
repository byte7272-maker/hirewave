# Project Harbor — AI Job Search Automation Platform

## 1. Project Description
Project Harbor is an AI-powered job search automation platform for active job seekers. It matches candidates to roles with semantic + skills/salary/location scoring, verifies postings for scams, generates tailored resumes and cover letters, auto-applies after human approval, and provides voice mock interview prep. Target users: mid-to-senior professionals in product, design, and engineering.
