# Hirewave — brand assets

All artwork uses the wave mark + accent blue `#2563eb`. Two groups: website
brand (for the Readdy app) and Chrome Web Store listing images (live under
`extension/`).

## Website brand (use in the Readdy app)

| File | Use |
|---|---|
| `hirewave-logo.svg` | Header/nav logo (scalable, transparent). Preferred. |
| `hirewave-logo-1072x256.png` | Header logo, raster @ high-res (transparent). |
| `hirewave-logo-536x128.png` | Header logo, raster @ 1x (transparent). |
| `hirewave-mark.svg` | Square app/badge mark (scalable). |
| `hirewave-mark-512.png` | PWA / web-app manifest icon. |
| `hirewave-mark-180.png` | Apple touch icon. |
| `hirewave-mark-48.png` | Spare mid-size icon. |
| `hirewave-mark-32.png` | Favicon. |
| `hirewave-mark-16.png` | Favicon (small). |

These replace the old "H" logo/favicon in Readdy.

## Chrome Web Store listing images (the "image upload" fields)

These live with the extension and are already Hirewave-branded:

| Store field | File | Notes |
|---|---|---|
| Store icon (128x128) | `extension/icons/icon128.png` | Comes from the packaged manifest icon; the wave mark. |
| Screenshot (1280x800, >=1 required) | `extension/store-assets/screenshot-1280x800.png` | Hirewave, code-free connect flow. |
| Small promo tile (440x280, optional) | `extension/store-assets/promo-440x280.png` | "Hirewave Connect". |
| Marquee promo tile (1400x560, optional) | `extension/store-assets/marquee-1400x560.png` | "Hirewave Connect" with a wave watermark. |

The packaged extension icons (`extension/icons/icon{16,32,48,128}.png`) are the
wave mark and ship inside `extension/dist/hirewave-connect-1.1.0.zip`.
